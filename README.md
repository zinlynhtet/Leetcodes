# LeetCode Problem Collection

A growing collection of LeetCode solutions. I will solve and document at least one problem every day, adding each solution to this README as the collection grows.

## Goal

- Solve at least 1 LeetCode problem each day.
- Keep one solution file per problem or problem group.
- Record the problem, difficulty, topic, approach, and date completed.
- Prefer clear solutions with time and space complexity notes.
- Continue adding problems until the collection covers the full range of LeetCode topics and difficulty levels.
